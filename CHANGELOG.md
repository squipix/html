# Changelog

All notable changes to this project will be documented in this file.

## [1.0.1] - 2026-09-30

### Added
- Initial release of Squipix HTML as a drop-in replacement for `collective/html`.

### Changed
- Updated for Laravel 12 and PHP 8.2+ compatibility.
- Package name changed to `squipix/html`.
- Namespaces changed to `Squipix\\Html`.

### Fixed
- Resolved PHP and PHPUnit deprecations.
